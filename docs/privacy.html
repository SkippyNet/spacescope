SpaceScope

Privacy policy

Last updated 13 November 2026.

The program

SpaceScope collects nothing. It has no accounts, no telemetry, no analytics, no crash reporting and no update check. It makes no network connections of its own.

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it.

What it reads stays on your computer: the names, sizes and dates of the files in the folder you ask it to scan, held in memory while the window is open. A CSV export is written only where you choose to save it. Its only saved setting file holds your preferences (theme, detail level and similar), in your user profile.

This website

The site is static pages hosted by GitHub Pages and sets no cookies. Loading it makes requests to three other services, each of which sees your IP address as any web server does:

  • GitHub Pages, which serves the pages (GitHub's privacy statement).
  • The GitHub API, asked once per visit for the public list of releases shown on the home page.
  • Google Fonts, which serves the typeface (Google Fonts privacy FAQ).

Downloads are served by GitHub. The download counts shown are the public totals GitHub reports; nothing identifies who downloaded.
